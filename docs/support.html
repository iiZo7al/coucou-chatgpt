FAQ

macOS says it can’t verify the app

The current Mac build isn’t notarized by Apple yet. The first time, open System Settings → Privacy & Security, scroll down and click Open Anyway. You only need to do it once.

Windows SmartScreen blocks the installer

The Windows installer isn’t code-signed yet, so SmartScreen warns about any app it hasn’t seen before. Click More info, then Run anyway. Coucou installs for your user only and needs no administrator rights.

Mochi doesn’t show my Codex sessions

Open Settings → Codex → Install hooks, review the changes, confirm, then start a new Codex session.

The chat doesn’t answer

Add your OpenAI API key in Settings. API usage is billed by OpenAI, separately from a ChatGPT subscription.

An integration pill stays grey

Check its key in Settings → Integrations. Up to 4 integrations can be shown at once.

No sound

Check the speaker icon in the notch header and the volume in Settings.

How do I uninstall?

Settings → Codex → Uninstall (removes only Coucou’s hooks), then quit the app and move it to the Trash. Optionally delete ~/Library/Application Support/NotchBuddy.

On Windows: same Uninstall button for the hooks, then Windows Settings → Apps → Coucou → Uninstall. Optionally delete %LOCALAPPDATA%\Coucou.

Questions fréquentes

macOS dit qu’il ne peut pas vérifier l’app

La version Mac actuelle n’est pas encore notarisée par Apple. La première fois, ouvre Réglages Système → Confidentialité et sécurité, descends et clique sur Ouvrir quand même. Une seule fois suffit.

SmartScreen bloque l’installeur Windows

L’installeur Windows n’est pas encore signé, donc SmartScreen prévient pour toute app qu’il ne connaît pas. Clique sur Informations complémentaires, puis Exécuter quand même. Coucou s’installe pour ton compte seulement et ne demande aucun droit administrateur.

Mochi n’affiche pas mes sessions Codex

Réglages → Codex → Install hooks, vérifie les changements, confirme, puis lance une nouvelle session Codex.

Le chat ne répond pas

Ajoute ta clé d’API OpenAI dans les Réglages. L’API est facturée par OpenAI, à part d’un abonnement ChatGPT.

Une pastille d’intégration reste grise

Vérifie sa clé dans Réglages → Intégrations. Jusqu’à 4 intégrations s’affichent en même temps.

Pas de son

Vérifie l’icône haut-parleur dans l’en-tête du notch et le volume dans les Réglages.

Comment désinstaller ?

Réglages → Codex → Uninstall (retire seulement les hooks de Coucou), puis quitte l’app et mets-la à la corbeille. Tu peux aussi supprimer ~/Library/Application Support/NotchBuddy.

Sous Windows : le même bouton Uninstall pour les hooks, puis Paramètres Windows → Applications → Coucou → Désinstaller. Tu peux aussi supprimer %LOCALAPPDATA%\Coucou.
